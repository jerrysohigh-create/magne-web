Calls and messages / contacts

Contacts, import/export and number blocking

Use this chapter to prepare and check the contacts, import/export and number blocking workflow on this firmware.

MAG1WW60-1 · demonstration pending

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

App list → Contacts

Before you start

  • Use a dummy contact and confirm its save account.

Reference steps · see recorded scope below

  1. Inspect the active account, then create a test contact with a non-dialable placeholder.
  2. Save, search and reopen it to verify the fields and account location.
  3. Inspect import and export controls before handling a contact file; confirm destination account and duplicates before importing.
  4. For number blocking, inspect the contact or Phone menu; remove only the test contact when finished.
