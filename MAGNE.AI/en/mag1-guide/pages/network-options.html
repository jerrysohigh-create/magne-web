Network and connections / network-options

Airplane mode, Data Saver, VPN and Private DNS

Treat connection controls separately when troubleshooting. Changing several at once makes diagnosis harder.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → Network & internet

Before you start

  • Record original switches and DNS/VPN configuration
  • The current network is not changed during this capture series to avoid interrupting active services
  • VPN credentials are not captured

Steps

View this session's screenshots and videos ↓

  1. Open Network & internet and inspect Airplane mode, Data Saver, VPN and Private DNS.
  2. Airplane mode affects wireless connections. When restoring connectivity, check Wi-Fi, Bluetooth and mobile service separately; do not assume every switch turns on together.
  3. Data Saver mainly affects background data. Also check per-app background allowances when investigating alerts.
  4. Use only a trusted VPN service and owner-provided configuration. Do not create an unknown connection for a screenshot.
  5. Record the original Private DNS setting before changing it. Obtain the hostname from a trusted DNS service; a wrong value may prevent domain resolution.
  6. Temporarily change only one setting at a time, record the result and restore it afterward.

Expected result and recorded evidence

All four entries were captured. Switch changes, DNS resolution and VPN connectivity were not tested.

Cancel, exit and restore

Restore the original switches and trusted configuration. Revert DNS if connectivity fails after a change.

Troubleshooting

  • Domains fail while IP addresses work: check DNS
  • Only background apps lack data: check Data Saver exceptions
  • All apps lose connectivity: check Airplane mode and VPN status

Limits and versions

Accounts, server credentials and personal VPN configurations are not displayed.
