Security is notone wall.It is three distinct gates.

The main system, signature and recovery are designed separately. Even if one layer faces risks, the other layers still maintain their boundaries.

III

Safety factors · CHIP ARCHITECTURE

Three safety factors,
Three paths that cannot be confused.

L1UTEE

Put sensitive processes into trusted execution boundaries.

L2HYPERSEED N60

Store the key in a secure element and complete the signature.

L3HYPERSEED 72B

Save the recovery path with a separate NFC chip.

L1 / UTEE

Trusted execution environment

Normal World and Secure World are separated by the TrustZone boundary, and sensitive APIs, key services and secure storage are only completed on the trusted side.

Reading summary Normal World TrustZone Secure World

General systems can initiate requests, but sensitive APIs, key services, and secure storage remain within the trusted execution boundary.

L2 / N60

Secure element signature

The NFC Controller is connected to the eSE via a controlled channel. Key storage, random numbers, encryption acceleration, and tamper detection converge within the secure element.

Reading summary NFCC SWP eSE

NFC communication and security components work separately, and signatures, keys, random numbers, and tamper detection converge at the hardware security boundary.

L3 / 72B

NFC recovery chip

A dedicated secure processor protects offline recovery material. It does not vouch for the main system; it preserves an independently authorized path back to ownership.

Reading summary Secure Core NFC RF Recovery Payload

Recovery data follows a separate chip path to keep device loss, primary system failure, and ownership recovery separate.
