Security and recovery / reset-scope

Reset options: networks, app preferences and factory reset

Understand the different effects of network, app-preference and factory-reset options. This page explains them without performing a reset.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → System → Reset options

Before you start

  • A complete, verifiable backup
  • Owner credentials and recovery prerequisites
  • Resetting is not required to follow this guide

Reference steps · see recorded scope below

  1. Open Reset options only to view the list. Do not select subsequent execution controls.
  2. The device shows Reset Mobile Network Settings, Reset Bluetooth & Wi-Fi, Reset app preferences and Erase all data (factory reset).
  3. Diagnose network issues through ordinary settings first. Mobile network and Bluetooth/Wi-Fi have separate reset entries; exact effects depend on their confirmation pages.
  4. Resetting app preferences may affect defaults, permissions and other configuration. It is not the same as clearing one app's cache. The confirmation page was not opened.
  5. A factory reset affects device data and authentication protections and requires separate confirmation and verified backups. It is not performed here.
  6. If another version shows more reset items, verify them again. Do not import another Android version's menu into this guide.

Cancel, exit and restore

Go back to exit. Data and preferences may not be recoverable after execution, so do not use this page for a live reset exercise.

Troubleshooting

  • Trying to recover a wallet by resetting: stop; a system reset is not wallet recovery
  • Cannot authenticate: the owner must use the normal recovery process
  • No backup: do not proceed

Limits and versions

Only the list is verified; reset effects were not tested. Firmware flashing and data erasure have not been tested.
