TROUBLESHOOTING / 故障排查

先定位，
再改變一項。

記錄發生時間、版本、錯誤文字和復現步驟。認證、付款、刪除、重置前停下；不要把清空資料當作第一步。

症狀先做什麼相關步驟
無法聯網先看飛航模式和 Internet，再檢查 SIM、VPN、DNS 與門戶認證。一次只改一項。開啟指南 →
通知延遲按 App 通知 → 渠道 → 勿擾 → Battery 自啟動/鎖屏停止 → 網路逐層檢查。開啟指南 →
螢幕看不清/熄屏快檢查 Display 中亮度、自動亮度、Screen timeout 和輔助顯示設定。開啟指南 →
聲音或振動異常區分媒體、通話、鈴聲、通知、鬧鐘；檢查耳機輸出及勿擾。開啟指南 →
USB 只充電檢查資料線、解鎖、USB 用途及電腦識別；勿把充電線當資料線。開啟指南 →
藍芽搜不到配件進入配對模式，核對距離與身份；配對碼不一致立即取消。開啟指南 →
空間不足先看 Storage 分類，再處理已確認備份的內容；不清錢包資料。開啟指南 →
錢包打不開/恢復失敗保留資料，核對包與版本；缺測試賬戶或認證時停在確認前。開啟指南 →
系統版本不同對照實際 Build 與地區，重新確認入口；當前不安裝更新或刷機。開啟指南 →
進液/破損/異常發熱停止使用和充電，聯絡官方支援；當前規格不承諾浸水使用。開啟指南 →

聯絡支援前準備

  • 產品型號和 Build；App 名稱、包名與版本。
  • 錯誤文字、發生時間、網路/配件條件、最短復現步驟。
  • 無個人資料的截圖；只透過私密官方渠道提供必要訂單資訊。
  • 不要傳送私鑰、助記詞、密碼、驗證碼或公開個人身份材料。

產品支援入口見官網 Contact 頁面：official@magne.ai。沒有傳送外部訊息；保修期限和服務條款等待正式政策。
