系統設定 / updates

系統更新、版本與重置邊界

確認適用版本；把檢視版本、檢查更新、安裝更新和重置分開。

入口已核驗 · 操作待核驗

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → System → System updates；Reset options

前置條件

  • 電量與穩定網路
  • 重要資料已有獨立備份
  • 本批不安裝更新、不刷機、不重置

逐步操作

  1. 檢視型號、Android 版本、系統 Build 和安全補丁日期；本次裝置為 MAG1WW53 / Android 15 / 2025-12-05。
  2. 進入 System 的更新入口檢視狀態，不因為一條“最新”提示推斷所有地區版本相同。
  3. 若有更新，先記錄版本、說明與適用地區；安裝前確認備份、電量及應用相容性。
  4. 更新下載、安裝、重啟及重新驗證是不同步驟，當前不替使用者執行。
  5. Reset options 中每個重置專案影響不同：網路重置不等於整機恢復，具體提示須逐項讀取。
  6. 恢復出廠、刷機和清除應用資料都需單獨授權及完整備份驗證。
