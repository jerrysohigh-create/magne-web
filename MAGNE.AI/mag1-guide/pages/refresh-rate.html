系統設定 / refresh-rate

螢幕重新整理率：Auto、60Hz、120Hz

選擇流暢度與功耗之間的設定；本機當前 UI 不提供 90Hz 選項。

指定操作已核驗 · 待同事複核

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → Display → Screen Refresh Rate

前置條件

  • MAG1WW53
  • 記錄當前選中項
  • 普通文字/滾動畫面，避免受保護內容

逐步操作

  1. 進入 Display，向下滾動，點 Screen Refresh Rate。

    檢視本步截圖 ↗

  2. 本次子頁面確認只有 Auto、60Hz、120Hz，閱讀下面關於功耗的提示。

    檢視本步截圖 ↗

  3. 本次從 Auto 點選 60Hz，確認單選項選中標記變為 60Hz；採集截圖後重新點 Auto，並確認恢復原選中項。實際操作已錄屏。

    檢視本步截圖 ↗ 檢視本步截圖 ↗ 檢視本步影片 ↗

  4. 用相同 App 和同一滾動內容觀察，記錄省電模式及溫度；不能把主觀流暢度當作幀率測量。
  5. 若 App 不按上限執行，核對 App 自身限制及 Auto/省電行為。

按鈕與選項

按鈕 / 選項用途與邊界
Auto自動策略，實際切換規則未測量
60Hz60Hz 選項
120Hz120Hz 選項，頁面提示可能更耗電

  • Auto

  • A higher screen refresh rate will bring a smoother visual experience, but will consume more power.

標籤出現只證明入口/選項可見；此列表不代表所有專案已操作。

正常結果與本次證據

選單有 Auto、60Hz、120Hz；已執行 Auto → 60Hz → Auto 並驗證選中狀態，恢復完成。實際顯示幀率、功耗和 120Hz 選擇分支未測試。

已核驗範圍：Screen Refresh Rate 的選中項 Auto → 60Hz → Auto；已核對並恢復原選擇。未測實際幀率或功耗。

取消、關閉與恢復

恢復原選中項；返回退出。

報錯與排查

  • 找不到 90Hz：本版本 UI 未提供，不是操作遺漏
  • 120Hz 下仍感覺不流暢：核對 App、負載、省電與溫度
  • 耗電變化：控制亮度/內容後再比較

限制與版本

僅設定選中項切換及恢復經過本次核驗；未測量實際幀率、功耗或 App 幀率。MAG1WW53 當前 UI 未提供 90Hz，不能套用官網規格檔位。
