Network and connections / usb

USB file transfer, charging and tethering

Distinguish USB connection purposes and avoid granting file access to an untrusted computer.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → Connected devices → USB

Before you start

  • Trusted computer and data-capable USB cable
  • Phone unlocked
  • Use non-sensitive test files; personal files are outside the demonstrated scope

Reference steps · see recorded scope below

View dated screenshots and videos ↓

  1. Connect the USB-C cable to a trusted computer.
  2. Open USB under Connected devices; this entry was observed in this session.
  3. Check which device controls USB and the actual Use USB for options, shown in this page's USB screenshot.
  4. To copy test files, select the available File transfer mode and use only the prepared test folder on the computer.
  5. When data is not needed, choose no-data or charging-only mode. USB debugging is a separate developer setting, not ordinary file transfer.
  6. Wait for copying to finish before unplugging. Do not interrupt a file write.

MAG1WW60-1 observed scope

Menu visibility and recorded navigation only; no setting changes.

Cancel, exit and restore

Return to no-data or charging-only mode and unplug. The owner should confirm the relevant computer before removing an unneeded debugging authorization.

Troubleshooting

  • Computer only charges the phone: check the cable, lock state and selected USB use
  • Transfer interrupted: check the port, cable and computer drivers
  • USB option unavailable: confirm that the cable is connected

Limits and versions

The website specifies USB 2.0. USB-C does not by itself imply DisplayPort or wired casting support.

16 October supplement · MAG1WW60-1 development software

  • The unchanged cable/host connection negotiated USB High-Speed: 480 Mbit/s bus signaling, not measured file-copy speed. The controller’s super-speed-plus limit does not prove the external port supports that speed.
  • The connected phone was a data device and power sink. Dual-role/OTG and audio-accessory declarations are present, but USB drives, reverse power and analog adapters were not tested.
  • Local PD revision is 3.0. The driver reported a fixed 5 V / 3 A profile (15 W nominal); this is neither measured absorbed power nor the phone’s maximum charging rating. PPS was not selected or tested.
  • No display was attached. Local DP Alternate Mode registration does not prove a negotiated video link; DP transmitter/redriver nodes are disabled on this build. Do not buy a display adapter on this evidence alone.
