Network and connections / wifi

Wi-Fi and internet troubleshooting

Connect to trusted Wi-Fi and distinguish a router connection from working internet access.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → Network & internet → Internet

Before you start

  • Your own Wi-Fi network and password
  • Do not record or display passwords, QR codes or real network names
  • The user must complete captive-portal authentication

Steps

  1. Open Network & internet → Internet. This entry was verified; nearby networks are excluded from the public captures.
  2. If Wi-Fi is off, use the actual switch and wait for the network list to refresh.
  3. Select your trusted network, confirm its name, enter the password on the device and connect as prompted.
  4. Check the connection status, then open a known working website. “Connected” alone does not guarantee internet access.
  5. If prompted to sign in to the network, complete its captive portal. Do not enter sensitive account credentials on an unknown network.
  6. To disconnect, use Disconnect on the network details page or turn off Wi-Fi. Forget deletes saved network information; use it carefully.

A visible label confirms that an entry or option exists. It does not mean every listed action has been tested.

Expected result and recorded evidence

Successful internet access is expected. No real network was added, forgotten or changed in this session.

Cancel, exit and restore

Turn off Wi-Fi or disconnect the test network. If the original network was forgotten, reconnect using the correct password.

Troubleshooting

  • Authentication failed: check the password and network selection
  • Connected without internet: check the captive portal, router, VPN and Private DNS
  • Network missing: check distance, supported bands and router broadcasting

Limits and versions

The Internet entry was verified. Password entry, connection results and network-details controls require review on a test network.
