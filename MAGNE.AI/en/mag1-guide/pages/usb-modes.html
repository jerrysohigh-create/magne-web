Network and connections / usb-modes

USB modes, AVC conversion and power output

Understand the actual mode list, including files, photos, MIDI and power options.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → Connected devices → USB

Before you start

  • A trusted computer or compatible device
  • A data cable
  • Test files and accessories; this review does not switch the active ADB connection

Steps

  1. Open USB and first review USB controlled by: Connected device / This device.
  2. Use USB for offers File Transfer, USB tethering, MIDI, PTP and No data transfer. Choose one purpose at a time.
  3. Use File Transfer for files, PTP for photo transfer where supported by the receiver, and MIDI with compatible music equipment or software.
  4. Convert videos to AVC is a switch under File transfer options. Conversion scope, output and processing time were not tested.
  5. Scroll to Power options → Charge connected device. This is a power option, not evidence of measured reverse-charging power or universal compatibility.
  6. When finished, return to a suitable no-data mode and disconnect after transfers finish. Do not switch modes during writes.

Expected result and recorded evidence

Modes and options were seen on the device. The active ADB connection was preserved; no mode switching, file conversion or reverse-power test was performed.

Cancel, exit and restore

Restore the original controlling device, USB mode and both switches. Disconnect only after writes finish.

Troubleshooting

  • Mode switch disconnects ADB: the owner should restore the required USB purpose and debugging settings
  • Photo software does not recognize the device: check PTP and computer drivers
  • Power output fails: check the accessory, cable and battery conditions

Limits and versions

An option's presence does not establish peripheral compatibility. USB-C video output is not verified.
