系統設定 / screen-timeout

螢幕超時與 Screen attention

決定無操作多久熄屏；Screen attention 使用前置相機檢測觀看狀態，需閱讀說明。

入口已核驗 · 操作待核驗

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → Display → Screen timeout

前置條件

  • 記下原超時值
  • 超時變長可能更耗電
  • 不把熄屏與關機混淆

逐步操作

查看本批截圖與操作影片 ↓

  1. 進入 Screen timeout。
  2. 本機顯示 15 seconds、30 seconds、1 minute、2 minutes、5 minutes、10 minutes、30 minutes。
  3. 按需要選擇一個時間；本次沒有修改選中值。
  4. Screen attention 作為另一個開關檢查；本機頁面說明使用前置相機進行觀看檢測，並宣告裝置內處理。該宣告是 UI 文字，本批未做資料流驗證。
  5. 實際測試時放置普通頁面不操作，記錄熄屏時間與 App 是否阻止休眠，隨後恢復原值。

正常結果與本次證據

七檔時間及 Screen attention 已截圖；計時和觀看檢測未測試。

取消、關閉與恢復

恢復原超時與 Screen attention 開關；不需要重啟或恢復出廠。

報錯與排查

  • 一直不熄屏：檢查播放/導航等 App 是否保持螢幕
  • 很快熄屏：檢查超時、省電或應用行為
  • 觀看檢測無效：核對開關、視線與環境

限制與版本
