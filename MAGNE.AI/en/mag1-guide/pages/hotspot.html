Network and connections / hotspot

Hotspot, USB tethering and Bluetooth tethering

Share the phone’s network with another device, distinguishing Wi-Fi hotspot from USB and Bluetooth tethering.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → Network & internet → Hotspot & tethering

Before you start

  • A test network and a second test device
  • Confirm that the plan permits tethering and has sufficient data
  • Do not record or publish the hotspot password

Reference steps · see recorded scope below

View dated screenshots and videos ↓

  1. Open Hotspot & tethering and check which sharing methods are actually shown.
  2. Wi-Fi hotspot: set a test name, strong password and an available band before enabling it. Do not infer 6 GHz or password-free support from an unopened subpage.
  3. On the second device, choose the test hotspot, enter the password and check a known working website.
  4. USB tethering: connect a data-capable cable to the computer and wait for detection before checking whether USB tethering is selectable. A charging-only cable cannot transfer data.
  5. Bluetooth tethering: pair the test device first, then enable the actual sharing switch. The receiving device must support it.
  6. Turn off all sharing switches enabled for the test immediately afterward.

MAG1WW60-1 observed scope

Menu visibility and recorded navigation only; no setting changes.

Cancel, exit and restore

Turn off hotspot and tethering, and disconnect the receiver. Do not expose the password when restoring the original hotspot settings.

Troubleshooting

  • USB option unavailable: check the data cable, computer detection and connection state
  • Hotspot connects without internet: first check internet access on the phone itself
  • Heat or battery drain: turn off sharing and reduce the workload

Limits and versions

Accessories and a second device are required to verify the complete connection. A screen recording demonstrates only the interface flow.
