網路與連線 / usb-modes

USB 模式、AVC 轉換與對外供電

解釋本機實際模式列表，包括檔案、照片、MIDI 和電源選項。

MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → Connected devices → USB

前置條件

  • 可信電腦或相容裝置
  • 資料線
  • 準備測試檔案與相容配件。變更 USB 模式可能中斷目前的 ADB 連線。

操作參考 · 實測範圍見下方

  1. 開啟 USB，先檢視 USB controlled by：Connected device / This device。
  2. Use USB for 下本機顯示 File Transfer、USB tethering、MIDI、PTP、No data transfer。每次只選擇一種目的。
  3. 檔案傳輸用 File Transfer；僅需要照片傳輸可按接收端支援選擇 PTP；MIDI 需要音樂裝置/軟體。
  4. Convert videos to AVC 是 File transfer options 下的開關；實際轉換範圍、輸出結果及耗時未測試。
  5. 向下檢視 Power options → Charge connected device；這是電源選項，不表示已測到反向功率或相容所有裝置。
  6. 完成時回到安全的無資料方式並結束對端傳輸後拔線；不在正在寫入時切模式。

MAG1WW60-1 實際核對範圍

僅可見選單與錄製導覽；未變更設定。

取消、關閉與恢復

恢復原控制方、USB 模式與兩個開關；確認寫入結束後拔線。

報錯與排查

  • 模式切換導致 ADB 斷連：由機主在 USB 設定恢復所需用途和除錯
  • 照片軟體不識別：核對 PTP 與電腦驅動
  • 供電不工作：檢查配件、線材及電量條件

限制與版本

選項存在不等於對應外設測試透過；USB-C 影片輸出未證明。

本版素材狀態

請見上方具日期的 MAG1WW60-1 截圖與錄影。

10 月 16 日補充 · MAG1WW60-1 開發軟體版本

  • 原有線材／主機連線協商為 USB High-Speed：480 Mbit/s 是匯流排訊號速率，不是檔案拷貝實測。控制器宣告 super-speed-plus 上限，不證明外部連接埠可達該速度。
  • 當時手機為資料裝置及電力接收端。雖有雙角色／OTG 與音訊配件宣告，但未測 USB 隨身碟、反向供電或類比轉接頭。
  • 本地 PD 版本欄位為 3.0；驅動回報固定 5 V／3 A 檔位，名義為 15 W，不是實際吸收功率，也不是整機最高充電功率。未選用或測試 PPS。
  • 未連接顯示器；本地 DP Alternate Mode 註冊不等於已建立視訊鏈路，此韌體的 DP 發射器／redriver 節點停用。不可只憑此證據購買螢幕轉接器。
