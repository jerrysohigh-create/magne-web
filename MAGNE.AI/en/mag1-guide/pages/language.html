Getting started / language

System and app languages

Switch system menus to English to match the screenshots. Keep Chinese in the language list so you can switch back later.

Specified operation verified · Peer review pending

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → System → Languages → System Languages

Before you start

  • Device unlocked
  • Screenshots use English (United States)
  • Changing the language may also affect regional formats and some app interfaces

Steps

View this session's screenshots and videos ↓

  1. Open Settings, scroll to System, then open Languages and System Languages.

    View screenshot for this step ↗ View screenshot for this step ↗

  2. If English (United States) is already listed, press and hold its drag handle on the right and move it to position 1. Tapping the language name does not reorder it.

    View screenshot for this step ↗

  3. When asked “Change system language to English (United States)?”, select Change.
  4. If English is missing, select Add a language, choose English and a region, then drag it to position 1. Adding a new language has not been tested in this session.
  5. Return to Settings and check that headings such as Network & internet and Display are in English. Some app names may remain in Chinese even after a successful change.

    View screenshot for this step ↗

A visible label confirms that an entry or option exists. It does not mean every listed action has been tested.

Expected result and recorded evidence

English (United States) was moved from position 2 to position 1, and the English Settings page was confirmed.

Verified scope: moved the existing English (United States) entry from position 2 to position 1, selected Change and checked English Settings.

Cancel, exit and restore

In the same list, move Simplified Chinese (China) back to position 1 and confirm Change. There is no need to delete English or Traditional Chinese.

Troubleshooting

  • Order unchanged: drag the handle on the right instead of tapping the language name
  • Some apps remain in Chinese: check App languages or the app’s own language setting; do not interrupt ongoing work unnecessarily
  • Menu not found: search Settings for “language” and check the system version

Limits and versions

MAG1WW53 / Android 15. Reordering and confirming the language were tested. Adding a language and changing individual app languages were not tested.
