Camera and tools / recorder

Audio recording, playback, export and deletion

Use this chapter to prepare and check the audio recording, playback, export and deletion workflow on this firmware.

Reference draft · On-device verification pending

MAG1WW53 · Android 15 · 2026-10-14

App list → Recorder (confirm local label)

Before you start

  • Use a short non-personal test phrase and obtain consent from anyone recorded.

Reference steps

  1. Open the recorder and inspect microphone permission and the recording control.
  2. Record a short test phrase, stop, then name and save the clip using the controls offered.
  3. Play the saved clip to check audibility. If export or Share is offered, inspect the destination before sending.
  4. Delete only the test clip after checking whether a trash or recovery option is available.

Exit and restore

Return to the previous page. If you choose to try these steps, restore only settings changed for that test and remove only its test data.

Troubleshooting
