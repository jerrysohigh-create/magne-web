網路與連線 / usb

USB 資料傳輸、充電與共享模式

區分 USB 連線用途，避免向不可信電腦開放檔案訪問。

入口已核驗 · 操作待核驗

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → Connected devices → USB

前置條件

  • 可信電腦與支援資料的 USB 線
  • 手機已解鎖
  • 用非敏感測試檔案，當前不讀取使用者儲存

逐步操作

查看本批截圖與操作影片 ↓

  1. 將 USB-C 線接入可信電腦。
  2. 在 Connected devices 中開啟 USB；該入口本次已看到。
  3. 核對 USB 由誰控制以及 Use USB for 的實際選項；實際列表見本頁 USB 截圖。
  4. 需要複製測試檔案時選擇頁面提供的 File transfer 模式，在電腦僅處理預先準備的測試目錄。
  5. 不需要資料時選擇無資料/僅充電方式；USB debugging 是另一個開發者設定，不等於普通檔案傳輸。
  6. 確認電腦複製已結束，再斷開線材；不要中斷正在寫入的檔案。

按鈕與選項

按鈕 / 選項用途與邊界
USB 控制方由當前裝置或連線裝置控制；實際可用性依對端
File transfer檔案傳輸，需裝置解鎖和資料線
USB tethering網路共享，與檔案傳輸不同
充電有電不代表資料線可用

正常結果與本次證據

本次 ADB 資料鏈路已可用；不以此聲稱 MTP 檔案傳輸、反向供電或影片輸出已透過。

取消、關閉與恢復

切回無資料/僅充電並拔線；關閉不再需要的除錯授權要由機主確認相應裝置。

報錯與排查

  • 電腦只充電：檢查線材、解鎖狀態和 USB 用途
  • 傳輸中斷：檢查介面、線材與電腦驅動
  • USB 項灰色：確認實際已連線

限制與版本

官網 USB 2.0；有 USB-C 不等於支援 DisplayPort 或有線投屏。
