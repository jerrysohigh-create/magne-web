系統設定 / memory-expansion

Memory expansion 記憶體擴充套件

借用部分儲存空間供系統擴充套件執行記憶體；不能把它當作新增物理 RAM 或保證效能提升。

入口已核驗 · 操作待核驗

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → System → Memory expansion

前置條件

  • 有足夠可用儲存
  • 記錄原選擇
  • 不為測試觸發未知重啟或儲存變更

逐步操作

  1. 開啟 Memory expansion，閱讀頁面說明：功能可能佔用部分儲存空間。
  2. 本機截圖顯示 Off、4.0 GB、8.0 GB、12.0 GB。
  3. 需要修改前先核對可用儲存，以及點選後是否要求重啟；本批只瀏覽，沒有選擇新值。
  4. 若以後經確認啟用，記錄生效時間、重啟要求和儲存變化，再對同一負載做對比，不能只憑顯示值聲稱更快。
  5. 關閉時選擇 Off 並按實際提示完成，操作後重新檢查狀態。

按鈕與選項

按鈕 / 選項用途與邊界
Off不啟用擴充套件
4.0 / 8.0 / 12.0 GB可選擴充套件量，不是實體記憶體增加
儲存條件按實際系統提示判斷是否可用
本批實際看到的英文標籤
  • Off
  • 4.0 GB
  • 8.0 GB
  • 12.0 GB

標籤出現只證明入口/選項可見；此列表不代表所有專案已操作。

正常結果與本次證據

四檔及說明文字由截圖視覺核驗；未切換或重啟。

取消、關閉與恢復

恢復原檔位；是否需重啟由實際提示決定，不承諾立即無影響。

報錯與排查

  • 空間不足：先看 Storage，不自動清資料
  • 沒有效果：核對生效條件並控制測試負載
  • 提示重啟：儲存工作，另行確認，不在採集時執行
