Calculator and scientific functions

Perform a basic calculation, view the scientific keypad and clear the demonstration input.

Specified operation verified · Peer review pending

Baseline: MA1 · Android 15 · MAG1WW53. Capture date: 2026-10-14. This review verifies only addition, expanding/collapsing the scientific keypad and clearing input with AC.

Calculator

Before you start

  • Calculator is installed; use non-sensitive demonstration values.
  • If the input area contains an expression that must be kept, save it separately before starting the demonstration.

Steps

View this session's screenshots and videos ↓

  1. Open Calculator and check the input area to be used for the demonstration.
  2. Tap 2, +, 3 and = in sequence and verify that the result is 5.
  3. Tap Show scientific buttons to expand the scientific keypad. This verifies only that the panel opens; individual scientific functions were not tested.
  4. Tap Hide scientific buttons to return to the basic keypad.
  5. Use AC to clear the demonstration input while retaining existing history.

Buttons and options

  • + / =: enter an addition and confirm the result.
  • Show scientific buttons / Hide scientific buttons: expand or collapse the scientific keypad.
  • AC: clear the current input. History management and deletion were not used in this demonstration.

Expected result and recorded evidence

This review confirmed 2 + 3 = 5, expanded and collapsed the scientific keypad, and cleared the demonstration input with AC. The recording neither shows nor deletes existing history. Not all scientific functions were tested.

Cancel, exit and restore

Clear the demonstration input with AC, collapse the scientific keypad and go back. Do not clear existing history.

Troubleshooting

  • Different result: check the numbers and operator, then retry with non-sensitive test values.
  • Scientific keys missing: check the expand button and app version; do not assume the phone must be rotated.

Limits and versions

Calculator 9.3 (967717812) · com.google.android.calculator · MAG1WW53。

Only the listed demonstration is verified. History management, copying, individual scientific functions and rotation were not tested. No unit or currency conversion capability is claimed. Peer review is pending; this page is unpublished.
