MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → System → Keyboard

前置條件

  • System → Keyboard 的實際子項及非敏感文字

操作參考 · 實測範圍見下方

查看附日期的截圖與操作影片 ↓

  1. 開啟 System → Keyboard。
  2. 進入 On-screen keyboard，核對已安裝輸入法及當前預設項；不把任一第三方輸入法當出廠元件。
  3. 在無個人資訊的測試輸入框確認字母、數字、換行、選中、複製和貼上；本次驗證沒有讀取剪貼簿。
  4. Spell checker 管理拼寫檢查；Personal dictionary 可能有個人詞條，當前不進入內容。
  5. Pointer speed 與物理指標有關，需滑鼠；Redirect vibration 的影響須讀子頁再測試。
  6. 返回並恢復原輸入法，防止影響機主之後輸入密碼。

MAG1WW60-1 實際核對範圍

僅可見選單與錄製導覽；未變更設定。

取消、關閉與恢復

恢復原輸入法與設定；不要清空詞典或剪貼簿。

報錯與排查

  • 鍵盤不出現：檢查當前輸入法和是否接入物理鍵盤
  • 語音失敗：檢查權限/網路/App 支援
  • 找不到輸入法：核對實際安裝

限制與版本

輸入法各自語言、語音及聯網能力需逐 App 核驗。
