MAGNE Network

從設備到鏈上的原生價值堆疊

MAGNE 不只是一部手機，而是通往雙鏈生態系統的設備原生入口。L1 承載所有權邏輯，L2 支援可擴展執行，而手機則作為主要接入點。

雙層鏈架構

MAGNE L1 負責所有權邏輯，MHash L2 負責可擴展執行。兩者共同構成從設備到鏈上的完整堆疊。

L1 — MAGNE

所有權層

MAGNE L1 是面向安全所有權、錢包邏輯與資產相關操作的基礎層。它承載私鑰保護、簽署流程，以及數字資產所有權規則的執行。

  • 私鑰儲存與密鑰隔離
  • 交易簽署（硬體支援）
  • 錢包邏輯與地址管理
  • 資產所有權記錄
  • 質押與驗證參與

L2 — MHASH

執行層

MHash L2 是為更廣泛應用與更低摩擦用戶互動而設計的可擴展執行層。智能合約在此運行，dApp 在此部署，用戶可在較低成本下與更廣泛的生態系統互動。

  • 智能合約執行
  • dApp 部署與託管

為什麼以設備作為入口？

MAGNE 不是一部額外安裝區塊鏈應用的手機，而是一個原生入口——設備與鏈從一開始即被共同設計。

密鑰留在設備內

私鑰在安全元件中產生並儲存，簽署流程由硬體支援。種子短語不以軟體形式存在。這不是增加幾個步驟的軟體錢包，而是內建於設備架構中的硬體級所有權能力。

鏈上互動是原生能力，而非單一應用

當您透過 MAGNE 存取 DeFi、dApp 或跨鏈橋時，互動流程會經由安全元件與 MAGNE/MHash 堆疊完成。您不是依賴瀏覽器擴充或第三方應用，而是透過設備原生架構與鏈互動。

一部設備，連接多條鏈

雙鏈架構意味著 MAGNE L1 負責所有權，MHash L2 負責執行。用戶不需要為每條鏈準備獨立電腦或硬體錢包，設備即可同時管理兩者。

無需雲端的復原能力

基於 NFC 的加密備份讓您可離線復原資產，無需手寫種子短語、無需雲端備份，也無需依賴第三方。設備本身即是密鑰與備份能力的一部分。
