MAGNE, AI and Web3 / call-translation

Local call translation and the system voice assistant

Use this chapter to prepare and check the local call translation and the system voice assistant workflow on this firmware.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Quick Settings → call-translation tile

Before you start

MAG1WW60-1 development software; VoiceAssistant 15.00001.22. Use a public automated service or a consented test partner. This session used 10086 automated prompts and did not select a paid service or request an agent.

Recorded MAG1WW60-1 operations

  1. In Quick settings → Edit and sort, locate Translate (VoiceAssistant) and add it if absent. The tile was not in this device’s initial layout.
  2. For the offline-data DEMO, turn off Wi-Fi and mobile data while leaving airplane mode off and cellular voice service available.
  3. Dial the public automated service 10086 using the test SIM. During the call, open Translate and check Chinese → English.
  4. Wait for model loading, then observe newly recognized Chinese speech and English output. Compare the texts; delays and errors can occur.
  5. End the call and restore the original Wi-Fi, mobile-data and shortcut settings.

Controls shown

The screenshots and videos below show the controls used in this session. Capabilities outside their stated scope remain untested.

MAG1WW60-1 observed scope

Translate (VoiceAssistant) is available in the quick-settings edit list on MAG1WW60-1. This screenshot verifies the entry only. MAG1WW60-1 on-device AI DEMO: new Chinese recognition and English output during a 10086 call with Wi-Fi and mobile data disabled. Four network checks passed. Output contains recognition and translation errors; related features are under active development. Silent screen recording. Network controls before the 10086 DEMO. ADB separately verified that both subscriptions had mobile data disabled and there was no default Internet network; cellular voice remained available.

After the test

The call was ended. Wi-Fi, mobile data and the original shortcut layout were restored after capture.

Troubleshooting

  • If the menu differs, record firmware and app versions and use the controls actually shown. Stop when a required credential or accessory is unavailable.

DEMO scope

This is an on-device AI capability DEMO. Related features remain under active, rapid development; output is for reference. Recognition and translation errors were observed. The test does not establish production accuracy, reverse-direction translation, speech synthesis or offline operation of other AI features. Cellular voice still requires the carrier network.

On-device AI capability DEMO

Related features are under active, rapid development. This demonstration shows current on-device capability; results are for reference.

In the 16 October 2026 MAG1WW60-1 test, Wi-Fi and mobile data were off before dialing 10086. New Chinese transcripts and English output appeared during the cellular voice call. ADB checks before, during and after the call confirmed Wi-Fi disabled, mobile data disabled on both subscriptions and no default Internet network. An existing VPN interface remained listed, with no physical Internet connection.

This supports local processing in the tested translation path with its installed models. It does not mean the telephone call itself is offline, or that every AI feature works without Internet access.

16 October supplement · MAG1WW60-1 development software

  • On MAG1WW60-1 with AI app 15.00001.22, a translation tile was temporarily added for a consented automated-service test call. It was absent from the initial Quick Settings layout, so this is not evidence that every user can find it there by default.
  • Enabling translation was followed by increasing NPU task counts; the llm_service process held /dev/vha0 and mapped the Qwen2.5-1.5B model. The user confirmed translation output. This supports NPU use in that tested call-translation path.
  • The second run added 15,121 completed driver tasks including tail work, with no driver failures in its samples. Task counts are not tokens and accumulated execution time is not translation latency.
