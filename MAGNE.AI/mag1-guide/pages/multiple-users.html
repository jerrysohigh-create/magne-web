安全與恢復 / multiple-users

多使用者與切換使用者

依本章準備並核對此韌體的「多使用者與切換使用者」操作流程。

MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → System → Users

前置條件

  • 使用機主帳戶並保留解鎖憑據。

操作參考 · 實測範圍見下方

  1. 開啟 Users，閱讀 Allow multiple users；頁面說明各使用者有自己的桌面、帳號、App 與設定。
  2. 確有需要才啟用，依實際流程建立使用者；Guest 訪客入口尚未確認。
  3. 加入帳號或檔案前核對目前使用者，並確認可切回機主。
  4. 刪除使用者前先匯出所需資料；切換使用者不需要刪除帳戶。

選項與範圍

已查看 Users 頁，未新增或切換使用者。

MAG1WW60-1 實際核對範圍

已查看 Users 設定及 Allow multiple users 控制項；未建立、切換或刪除使用者，設定未變更。

退出與還原

返回上一頁。若自行試行以上步驟，只恢復此次測試改動的設定，並只移除測試資料。

疑難排解

  • 選單不同時記錄韌體及 App 版本，以實際控制為準；缺少所需憑據或配件時停止該步驟。

限制與版本

Private space 是另一項功能；訪客模式、共享規則及使用者數量限制需另測。
