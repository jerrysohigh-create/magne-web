Network and connections / sim

SIMs, mobile data, default calling SIM and roaming

Manage mobile services. A SIM menu does not establish compatibility with every SIM, band or roaming service.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → Network & internet → SIMs

Before you start

  • A Nano-SIM and carrier service suitable for the region
  • Check the hardware diagram before inserting or removing a SIM
  • The owner must confirm any chargeable roaming, messaging or calls

Steps

  1. Install the Nano-SIM according to the device and supplied instructions. No SIM is inserted or removed on the user’s behalf in this session.
  2. Open SIMs and check whether the intended card is detected. Do not publish phone numbers, ICCIDs or IMSIs.
  3. Check mobile data, network type and default calling and messaging SIMs. The exact items require verification with a test SIM.
  4. With two SIMs, check data, calls and messages separately; do not assume they all use the same card.
  5. Confirm the plan and charges with the carrier before deciding to enable Data roaming.
  6. Use official carrier parameters for APN configuration, recording the original values first. Do not copy a template from another region.

Expected result and recorded evidence

The SIMs entry is visible. Phone numbers were not recorded, carrier settings were not changed and calls were not tested.

Cancel, exit and restore

Restore the original default SIM, data switch and APN. Disabling roaming does not cancel charges already incurred.

Troubleshooting

  • No SIM detected: check installation and the SIM itself
  • Signal but no internet: check the plan, APN and default data SIM
  • No 5G: check region, carrier, SIM, coverage and system version

Limits and versions

The official site lists dual Nano-SIM / DSDS and no eSIM. Carrier support needs separate verification.
