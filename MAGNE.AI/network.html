一筆簽章 · ONE SIGNATURE

從手指開始。
在公開紀錄中結束。

ADB VERIFIED DEVICE PATH HED NFC AIDL → Secure Element Service → eSE1 : CONNECTED

MAG1 確認採用 HyperSeed N60；ADB 驗證 Android 與安全元件的實機接入狀態，而不是用來猜測芯片型號。

查看安全架構 →
  1. 01 / INTENT應用意圖

    使用者在 App 或 DApp 發起交易、身份或資產操作。

  2. 02 / ASSISTAI 協助

    端側 AI 可以理解與整理意圖，但不能替使用者授權或簽署。

  3. 03 / AUTHORIZE本人授權

    生物辨識與明確確認，決定這次操作是否可以繼續。

  4. 04 / ROUTE安全路由

    Android 透過 OMAPI、Secure Element Service 與 HED 通道送出受控請求。

  5. 05 / SIGNN60 簽章

    請求經 eSE1 進入 HyperSeed N60；私鑰不被匯出，只返回簽章結果。

  6. 06 / EXECUTEL2 執行

    經簽署的應用交互在 MHash L2 被處理與批次化。

  7. 07 / RECORDL1 留存

    需要長期證明的狀態回到 MAGNE L1 結算與紀錄，形成公開可查的所有權歷史。
