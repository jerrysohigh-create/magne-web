本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → Display → Display size and text

前置條件

  • 記住原滑塊位置
  • 當前介面有預覽內容
  • 請依閱讀需求調整，並保留原設定以便恢復

操作參考 · 實測範圍見下方

查看附日期的截圖與操作影片 ↓

  1. 開啟 Display size and text。
  2. Font size 調整文字大小；Display size 調整整體介面比例，每次只改一個滑塊。
  3. 檢視預覽和普通設定頁的行距、按鈕、截斷情況，選擇能舒適閱讀且不遮擋操作的比例。
  4. 按需要分別檢視 Bold text 和 High contrast text 開關。
  5. 返回並開啟常用 App 驗證文字佈局；App 自己的字型規則可能不同。
