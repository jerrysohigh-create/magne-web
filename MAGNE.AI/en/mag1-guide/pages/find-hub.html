Security and recovery / find-hub

Find Hub: finding and protecting a lost phone

Find the MAG1 device-finding settings and understand what has been checked before relying on remote recovery.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → Security & privacy → Device finders → Find Hub

Before you start

  • For account-based Find Hub recovery, use the Google Account associated with the phone and keep a way to complete account verification from another device.
  • Check Location and Allow device to be located before the phone is lost. See Google’s preparation reference below.
  • For any demonstration, keep account details, maps, coordinates and other devices out of public captures.

Reference steps · see recorded scope below

  1. Open Settings → Security & privacy → Device finders. The inspected MAG1 showed Find Hub with the summary On.
  2. Open Find Hub and inspect Allow device to be located. It was enabled during the recorded check; no switch was changed.
  3. Open Remote Lock to inspect its separate setting. Use Remote Lock was Off on this device. Return without changing it if you are only reviewing the configuration.
  4. The Find Hub settings page provides Find Hub app and Find Hub web entries. Their presence was confirmed; the demonstration did not open an account device list or map.

If your phone is missing — service reference

The following is general Google guidance, not a recorded MAG1 test.

  1. On another device, open Find Hub, sign in to the phone’s Google Account and select the correct phone. Complete any requested identity check.
  2. Review the displayed location and its timestamp. Use Play sound for a nearby phone, or Mark as lost to lock it and provide return details. Availability depends on the service and device state.
  3. Factory reset permanently removes device data and ends further finding through Find Hub; an SD card may not be erased. Treat it as a last resort, not a routine test.

Exit and restore

Use Back to return from Remote Lock to Find Hub. This inspection changed no switches, accounts or permissions and sent no remote command.

Troubleshooting

  • If the phone is absent from the service, check the associated Google Account and follow Google’s preparation checklist. An installed app alone does not establish successful registration.
  • Do not interpret an old or unavailable location as a live position. Check the displayed time and connectivity.
  • If menus differ, record the firmware, Find Hub and Google Play services versions before comparing instructions.
