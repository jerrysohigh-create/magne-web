網路與連線 / network-options

飛航模式、流量節省、VPN 與 Private DNS

排查連線時把不同控制層分開，避免一次更改多項失去診斷依據。

MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → Network & internet

前置條件

  • 記錄原開關與 DNS/VPN 配置
  • 變更網路設定可能中斷正在使用的服務，請先儲存工作
  • VPN 憑據不採集

操作參考 · 實測範圍見下方

查看附日期的截圖與操作影片 ↓

  1. 進入 Network & internet，依次檢視 Airplane mode、Data Saver、VPN、Private DNS。
  2. 飛航模式會影響無線連線；恢復時檢查 Wi-Fi、藍牙及行動網路是否按預期恢復，不假設所有開關同時開啟。
  3. Data Saver 主要影響後臺資料；對提醒問題同時核對應用後臺允許策略。
  4. VPN 只使用可信服務與機主提供的配置；不要為截圖建立未知連線。
  5. Private DNS 修改前記錄原選項，主機名必須來自可信 DNS 服務；輸入錯誤可能導致域名無法解析。
  6. 排錯時只臨時改變一項並記錄結果，確認後恢復。

按鈕與選項

按鈕 / 選項用途與邊界
Airplane mode飛航模式
Data Saver流量節省
VPN隧道連線配置；不保證可以訪問任意地區服務
Private DNS加密 DNS 設定，不等於 VPN

取消、關閉與恢復

恢復原開關及可信配置；更改 DNS 後無法聯網時回到原選擇。

報錯與排查

  • 域名無法訪問但 IP 可通：檢查 DNS
  • 只有後臺 App 無資料：檢查 Data Saver 例外
  • 所有應用掉線：核對飛航模式和 VPN 狀態
