Home screen and everyday use / smart-motion

Smart motion call gestures

Inventory MAG1 call gestures. Determine each gesture's meaning from its instructions and an actual test call.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → Smart controls → Smart motion

Before you start

  • A test number and the other party's permission
  • Record original switch states
  • Without a test call, do not infer behavior from gesture names

Reference steps · see recorded scope below

View dated screenshots and videos ↓

  1. Open Smart motion and review Smart call, Easy answer, Easy bell and Mute incoming calls.
  2. Read each description to distinguish calling, answering, ringtone and mute behavior. Complete triggering gestures await an on-device demonstration and review.
  3. For testing, use a non-personal test contact and an agreed counterpart, enabling only one gesture at a time.
  4. During a test incoming call, record the gesture, screen state, proximity-sensor conditions and result. Muting is not rejecting or ending a call.
  5. Disable each test switch before trying the next gesture to prevent interactions.

MAG1WW60-1 observed scope

Menu visibility and recorded navigation only; no setting changes.

Cancel, exit and restore

Disable gestures enabled for testing and restore the original values. If a call is active, end it using the normal End call control.

Troubleshooting

  • Does not trigger: check the switch, screen, sensors and actual instructions
  • Accidental dialing: disable the item first; do not practice on real contacts
  • Ringtone changes: distinguish muting from rejecting a call

Limits and versions

A screen recording is not evidence of the physical gesture itself. Do not invent results without a test call.
