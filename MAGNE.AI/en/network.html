One signature · ONE SIGNATURE

Start with your fingers.
Ended on public record.

ADB VERIFIED DEVICE PATH HED NFC AIDL → Secure Element Service → eSE1 : CONNECTED

MAG1 confirms the use of HyperSeed N60; ADB verifies the actual access status of Android and secure elements, rather than guessing the chip model.

View security architecture →
  1. 01 / INTENTapplication intent

    Users initiate transactions, identity or asset operations in Apps or DApps.

  2. 02 / ASSISTAI assistance

    On-device AI can understand and organize intentions, but it cannot authorize or sign for the user.

  3. 03 / AUTHORIZEI authorize

    Biometric identification and clear confirmation determine whether the operation can continue.

  4. 04 / ROUTEsecure routing

    Android sends controlled requests through OMAPI, Secure Element Service, and HED channels.

  5. 05 / SIGNN60 signature

    The request enters HyperSeed N60 via eSE1; the private key is not exported and only the signature result is returned.

  6. 06 / EXECUTEL2 execution

    Signed application interactions are processed and batched in MHash L2.

  7. 07 / RECORDL1 retention

    Status requiring long-term certification goes back to MAGNE L1 settlement and records, forming a publicly available ownership history.
