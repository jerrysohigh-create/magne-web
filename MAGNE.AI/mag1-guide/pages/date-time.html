系統設定 / date-time

日期、時間、時區與地區偏好

完整目錄保留本項，當前缺少可公開的對應介面或測試條件。

入口已核驗 · 操作待核驗

適用基線：MA1 · Android 15 · MAG1WW53。採集：2026-10-14。本頁為編輯草稿；除明確說明的操作外，步驟未執行驗證。

Settings → System → Date & time

前置條件

  • System 內實際日期/時間入口

逐步操作

  1. 開啟 Date & time，先核對當前時間、時區及自動設定狀態。
  2. Set time automatically 決定日期時間來源；Date / Time 是否可編輯依該開關。
  3. Time zone 分組有 Set automatically 與 Use location，是否需要定位由頁面提示確認。
  4. Time format 分組有 Use locale default 和 Use 24-hour format。
  5. 若準備調整，只變一個選項，檢查普通時鐘頁面；當前不改裝置時間，避免影響認證、交易及定時任務。
  6. 需要恢復時按原自動設定及格式返回。

按鈕與選項

按鈕 / 選項用途與邊界
Set time automatically自動日期時間
Set automatically自動時區
Use location用於時區的定位選項
Use locale default使用地區預設時間格式
Use 24-hour format24小時顯示

取消、關閉與恢復

恢復原自動時間、時區與格式。

報錯與排查

  • 時間錯：檢查自動設定、網路和時區
  • 24小時無效：檢查地區預設開關
  • 認證異常：先核對時間，不隨意調回歷史日期

限制與版本
