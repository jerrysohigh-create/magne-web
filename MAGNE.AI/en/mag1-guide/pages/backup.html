Security and recovery / backup

Data backup and restore verification

Separate backup contents, storage destination and restore testing. System backup does not replace wallet-key backup.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → System → Backup (subpage awaiting verification); each app’s own export/backup

Before you start

  • Owner’s account and enough storage
  • Use test files and an account with no assets
  • Do not export passwords, private keys or recovery phrases

Reference steps · see recorded scope below

  1. List the photos, documents, contacts, authenticators, chats and app data to retain, then confirm each backup method separately.
  2. Check the Backup entry under System. Cloud backup availability depends on account, network, region and app support.
  3. Copy ordinary test files to independent trusted storage, then open them from the other location and check the contents.
  4. Use each app’s official backup workflow and identify data excluded from the backup.
  5. Test wallet recovery only in an environment without assets. A successful system cloud backup does not guarantee wallet recovery.
  6. Record the last successful time, backup destination and actual restore-test result. No restore was performed in this session.

Recorded entry and controls

The System overview shows the Backup entry. The backup subpage, account details and backup contents were not opened. No backup, restore or synchronization was started.

MAG1WW60-1 observed scope

Backup entry on the System overview only. Backup settings and account details were not opened; no backup, restore or synchronization was started.

After inspection

Return using Back. This capture did not change any network or security setting.

Troubleshooting

  • Backup fails: check network, space, sign-in and supported data
  • Restored data is missing: check whether that item was included in the backup
  • Wallet recovery information is unknown: do not clear data or reset the phone

16 October supplement · MAG1WW60-1 development software

  • HED NFC and SE services exist, but an external NFC backup card, the embedded SE and the platform TEE have distinct roles. No card model, backup/restore operation, lockout policy or cross-device recovery was validated in this report.
  • The wallet app handles decrypted recovery phrases during display/backup. Do not describe NFC backup as proof that recovery phrases never enter Android. Use only vendor-confirmed cards and wait for the analyzed build’s security fixes and recovery verification.
