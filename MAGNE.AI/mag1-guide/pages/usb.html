網路與連線 / usb

USB 資料傳輸、充電與共享模式

區分 USB 連線用途，避免向不可信電腦開放檔案訪問。

MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → Connected devices → USB

前置條件

  • 可信電腦與支援資料的 USB 線
  • 手機已解鎖
  • 用非敏感測試檔案，當前不讀取使用者儲存

操作參考 · 實測範圍見下方

查看附日期的截圖與操作影片 ↓

  1. 將 USB-C 線接入可信電腦。
  2. 在 Connected devices 中開啟 USB；該入口本次已看到。
  3. 核對 USB 由誰控制以及 Use USB for 的實際選項；實際列表見本頁 USB 截圖。
  4. 需要複製測試檔案時選擇頁面提供的 File transfer 模式，在電腦僅處理預先準備的測試目錄。
  5. 不需要資料時選擇無資料/僅充電方式；USB debugging 是另一個開發者設定，不等於普通檔案傳輸。
  6. 確認電腦複製已結束，再斷開線材；不要中斷正在寫入的檔案。

按鈕與選項

按鈕 / 選項用途與邊界
USB 控制方由當前裝置或連線裝置控制；實際可用性依對端
File transfer檔案傳輸，需裝置解鎖和資料線
USB tethering網路共享，與檔案傳輸不同
充電有電不代表資料線可用

MAG1WW60-1 實際核對範圍

僅可見選單與錄製導覽；未變更設定。

取消、關閉與恢復

切回無資料/僅充電並拔線；關閉不再需要的除錯授權要由機主確認相應裝置。

報錯與排查

  • 電腦只充電：檢查線材、解鎖狀態和 USB 用途
  • 傳輸中斷：檢查介面、線材與電腦驅動
  • USB 項灰色：確認實際已連線

限制與版本

官網 USB 2.0；有 USB-C 不等於支援 DisplayPort 或有線投屏。

本版素材狀態

請見上方具日期的 MAG1WW60-1 截圖與錄影。

10 月 16 日補充 · MAG1WW60-1 開發軟體版本

  • 原有線材／主機連線協商為 USB High-Speed：480 Mbit/s 是匯流排訊號速率，不是檔案拷貝實測。控制器宣告 super-speed-plus 上限，不證明外部連接埠可達該速度。
  • 當時手機為資料裝置及電力接收端。雖有雙角色／OTG 與音訊配件宣告，但未測 USB 隨身碟、反向供電或類比轉接頭。
  • 本地 PD 版本欄位為 3.0；驅動回報固定 5 V／3 A 檔位，名義為 15 W，不是實際吸收功率，也不是整機最高充電功率。未選用或測試 PPS。
  • 未連接顯示器；本地 DP Alternate Mode 註冊不等於已建立視訊鏈路，此韌體的 DP 發射器／redriver 節點停用。不可只憑此證據購買螢幕轉接器。
