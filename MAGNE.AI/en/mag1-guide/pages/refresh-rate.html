System settings / refresh-rate

Screen refresh rate: Auto, 60Hz and 120Hz

Choose a setting balancing smoothness and power use. The current device UI does not offer 90Hz.

MAG1WW60-1 · dated captures available

This chapter uses MAG1WW60-1 evidence only. Reference steps are separate from the actions actually recorded.

Settings → Display → Screen Refresh Rate

Before you start

  • Record the current selection
  • Ordinary text or scrolling content; avoid protected content

Reference steps · see recorded scope below

  1. Open Display, scroll down and tap Screen Refresh Rate.
  2. The captured subpage offers only Auto, 60Hz and 120Hz. Read the power-use note below them.
  3. The recorded demonstration changed Auto to 60Hz and confirmed the selected radio button, captured a screenshot, then selected Auto again and verified restoration. The operation was recorded.
  4. Observe the same app and scrolling content while recording power-saving mode and temperature. Subjective smoothness is not a frame-rate measurement.
  5. If an app does not run at the selected maximum, check its own limits and Auto/power-saving behavior.

MAG1WW60-1 observed scope

Menu visibility and recorded navigation only; no setting changes.

Verified scope: Screen Refresh Rate selection Auto → 60Hz → Auto, including restoration of the original setting. Actual frame rate and power use were not measured.

Cancel, exit and restore

Restore the original selection and go back to exit.

Troubleshooting

  • 90Hz missing: this UI version does not offer it; no step was omitted
  • 120Hz still feels uneven: check the app, load, power saving and temperature
  • Power-use differences: control brightness and content before comparing
