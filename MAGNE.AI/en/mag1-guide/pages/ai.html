Before you start

  • Test prompts without personal information

Reference steps · see recorded scope below

  1. gptos.intelligence.assistant 2.1.570 was found as a user-installed package. Its presence does not establish that it is factory-installed MAGNE AI.
  2. Inventory each AI app in actual use separately, including sign-in, input, voice, images, model selection, history, files, permissions and account deletion.
  3. Test text input and results using a prompt without personal information. If an account is required, pause only that app's test.
  4. Verify offline capability per application, with model identity, network conditions, fresh output and network restoration recorded. Completed console and call-translation demonstrations are scoped below.
  5. Voice and image features involve microphone/camera permissions and uploads. Establish where processing occurs and the service conditions.
  6. Check generated results for accuracy and limitations. Model output is not official evidence of device specifications.

MAG1WW60-1 observed scope

MAG1WW60-1 integrates dedicated camera visual-AI components and a separate local call-translation model path. The camera application and JN1 configuration contain scene-recognition, denoising, depth/segmentation and beauty components. Integration does not establish that every component executes in every mode.

In the MAG1WW60-1 call-translation test, the Qwen2.5-1.5B model service opened the NPU device and completed task counts increased after translation was enabled. This supports NPU use by that translation path. A subsequent DEMO produced new transcripts and translations with Wi-Fi and mobile data disabled; see the recorded test conditions below. The processor used by each ASR/TTS stage was not established.

Camera mode-by-mode runtime tracing remains pending. There is no current evidence that ordinary photography uses the translation language model, or that CPU, GPU and NPU simultaneously execute the same model.

Follow the workflow

  1. Connect the prepared MAG1 by USB, complete normal device authorization, start the local console, and choose English or Traditional Chinese.
  2. Select Check connection. Confirm MAG1WW60-1 and the required service state before testing.
  3. In Speech recognition, query languages and select Transcribe sample. Compare the returned text with “The weather is sunny today.” This tests a synthetic file, not live microphone capture.
  4. In Speech synthesis, choose the sample text, matching voice and speed; select Generate on phone. After success, play or download the WAV and review any warnings.
  5. Use Installed models to read each file’s purpose and evidence. File presence alone does not confirm active inference or acceleration.

04 / Gemma · separately installed experiment

Gemma 3n E2BExternal model · separate runtime
Model
Gemma 3n E2B IT · INT4 · LiteRT-LM
Purpose
A generative model for local text interaction and, when image support is enabled in the matching app, image questions. It is separate from camera depth, denoising and segmentation models.
How to use it
Google AI Edge Gallery → imported model → text chat or the image-enabled import → select a permitted picture and ask a short question. It is not a selectable FIH model in the current console.
Recorded evidence
English and Traditional Chinese text outputs, a three-run 64-input/64-output-token benchmark, and one image description were completed on MAG1WW60-1. Gallery 1.0.20 labels the LLM backend CPU; the image test logs also contain OpenCL activity, so the entire vision path is not claimed to be CPU-only.
Measured example
Gallery reported an average decode rate of 2.11 tokens/s across three runs. This is not directly comparable to Qwen/FIH because model, tokenizer, runtime and workload differ.
Limits and counting
The image-enabled import is a byte-identical copy of the same model, counted once. This does not establish FIH compatibility, NPU acceleration, real-time camera integration, audio support, long-context stability or general visual accuracy.
gemma-3n-E2B-it-int4.litertlm3,486.47 MiB

What is not counted as another model

  • LLM-based translation reuses Qwen. Gemma text and image imports reuse the same model artifact. Network parts and network/cadence pairs may belong to one processing pipeline.
  • Token lists, dictionaries, pronunciation data, finite-state text rules and voice embeddings support inference. The shared model directory contains 386 files, not 386 independently usable models. Some auxiliary files may themselves contain statistical data.
  • Gemini is described in its own chapter. An installed app or NPU driver is not proof of a locally installed Gemini model. Camera AI libraries without identified model files are components, not additional named models in this register.
