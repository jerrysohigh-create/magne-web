系統設定 / lockscreen-display

鎖屏內容、文字、裝置控制元件與喚醒

控制鎖屏展示；通知隱私與實際裝置解鎖是不同設定。

MAG1WW60-1 · 已有具日期素材

本章僅使用 MAG1WW60-1 證據。操作參考與實際錄製的動作分開說明。

Settings → Display → Lock screen

前置條件

  • 不用真實聯絡資訊做鎖屏文字示範
  • 記下原值
  • 喚醒效果使用無敏感通知的測試環境

操作參考 · 實測範圍見下方

  1. 進入 Lock screen，核對 Privacy 與 Add text on lock screen。
  2. 需要留言時僅輸入非敏感測試文字；公開電話號碼等可能被任何看到鎖屏的人讀到。
  3. 檢視 Show device controls 與 Use device controls，讀懂是否允許未解鎖操作；當前不改變權限。
  4. Dynamic clock 改變時鐘展示，效果要在實際鎖屏狀態核驗。
  5. Lift to check phone、Wake screen for notifications 分別對應抬起和通知喚醒；本頁未測試真實通知的喚醒效果。
  6. 返回鎖屏檢查安全展示，再恢復測試更改。

MAG1WW60-1 實際核對範圍

僅可見選單與錄製導覽；未變更設定。

取消、關閉與恢復

刪除測試文字，恢復控制元件、時鐘與喚醒的原設定。

報錯與排查

  • 通知內容仍露出：同時檢查 Notifications 的敏感內容設定
  • 抬起無反應：檢查目標開關與狀態
  • 不需要控制元件：關閉相關開關並核對鎖屏

限制與版本

展示設定不等於關閉裝置鎖定；認證憑據不在本頁修改。
