System settings / memory-expansion

Memory expansion

Uses some storage for system memory expansion. It does not add physical RAM or guarantee better performance.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → System → Memory expansion

Before you start

  • Sufficient available storage
  • Record the original selection
  • Do not trigger an unknown restart or storage change for testing

Steps

  1. Open Memory expansion and read the explanation that the feature may use some storage space.
  2. The device screenshot shows Off, 4.0 GB, 8.0 GB and 12.0 GB.
  3. Before changing it, check available storage and whether a restart is required. This review only browses and does not select a new value.
  4. If enabled later with confirmation, record when it takes effect, restart requirements and storage changes, then compare the same workload. A displayed capacity alone does not prove greater speed.
  5. To disable, select Off and follow the actual prompts, then recheck the state.

Expected result and recorded evidence

Four choices and explanatory text were visually verified in the screenshot. No selection change or restart was performed.

Cancel, exit and restore

Restore the original choice. Follow actual restart prompts; immediate, impact-free restoration is not guaranteed.

Troubleshooting

  • Insufficient space: inspect Storage first; do not automatically clear data
  • No effect: check activation requirements and control the test workload
  • Restart requested: save work and obtain separate confirmation; do not restart during capture

Limits and versions

The page name and choices are visible. Performance, storage usage and restart requirements were not tested.
