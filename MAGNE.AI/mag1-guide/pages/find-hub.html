安全與恢復 / find-hub

尋找裝置：Find Hub 與遺失手機保護

找到 MAG1 的裝置查找設定，了解目前已核驗的範圍，以及遠端尋回前需要確認的條件。

入口與設定已核對 · 遠端操作待驗證

MAG1WW53 · Android 15 · 2026-10-14

Settings → Security & privacy → Device finders → Find Hub

前置條件

  • 使用 Google 帳號型的 Find Hub 尋回功能時，請使用與手機關聯的帳號，並保留可在其他裝置完成帳號驗證的方法。
  • 在手機遺失前確認 Location 及 Allow device to be located；準備條件請參閱下方 Google 官方說明。
  • 若製作示範，請避免在公開素材中呈現帳號、地圖座標及其他裝置資料。

本機已核對的操作路徑

  1. 開啟 Settings → Security & privacy → Device finders。本次 MAG1 頁面顯示 Find Hub，摘要為 On。
  2. 進入 Find Hub，查看 Allow device to be located。本次核查為開啟，沒有變更開關。
  3. 進入 Remote Lock 查看獨立設定。本機 Use Remote Lock 為 Off；僅核對設定時，查看後返回即可。
  4. Find Hub 設定頁提供 Find Hub app 與 Find Hub web 入口。已確認入口可見，本次沒有開啟帳號裝置列表或地圖。

按鈕與目前設定

選項核查狀態與限制
Allow device to be located本次為 On。這是設定狀態，不代表已成功執行遠端定位。
系統 LocationADB 核查為開啟；定位精度未測試。
Remote Lock / Use Remote Lock本次為 Off。頁面說明可透過手機號碼遠端鎖屏；此選項與 Find Hub 主開關分開。
Find Hub app / Find Hub web兩個入口均可見；未執行帳號存取或遠端指令。
離線／關機查找所檢查設定頁沒有顯示離線查找選項；不能據此斷言支援或不支援。MAG1 的這兩項能力仍待驗證。

手機遺失時：官方服務參考

下列為 Google 通用操作參考，並非 MAG1 實測錄影。

  1. 在另一台裝置開啟 Find Hub，登入與手機關聯的 Google 帳號，選擇正確手機，並完成所要求的身分驗證。
  2. 查看位置及更新時間。手機在附近時可使用 Play sound；遺失時可用 Mark as lost 鎖定並留下聯絡資訊。實際可用性取決於服務與裝置狀態。
  3. Factory reset 會永久清除裝置資料，之後無法再透過 Find Hub 尋找該手機；SD 卡可能不會被清除。此操作應作最後手段，不作日常測試。

已核驗結果

2026-10-14 唯讀核查已確認設定路徑、Find Hub 為 On、Allow device to be located 為 On、系統定位開啟，以及 Remote Lock 為 Off。沒有執行遠端請求。

退出與還原

使用返回鍵從 Remote Lock 返回 Find Hub。本次沒有變更開關、帳號或權限，也沒有發送遠端指令。

疑難排解

  • 若服務中沒有顯示手機，先核對關聯 Google 帳號並依官方準備清單檢查。僅安裝 App 不代表已成功註冊。
  • 位置未更新或不可用時，不要將舊位置當作即時位置；請核對畫面時間及連線狀態。
  • 選單不同時，先記錄韌體、Find Hub 及 Google Play 服務版本，再對照操作說明。

基準：MAG1WW53 / Android 15，2026-10-14。Find Hub 3.1.763-04 為已更新的系統 App，另有出廠版本 3.1.337-2；Google Play 服務為 26.37.37。未測定位、響鈴、遺失模式、遠端鎖屏、清除、離線及關機查找。韌體或 Google 元件更新後須重新核對本章。
