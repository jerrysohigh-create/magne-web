IVEXTENSIBLE AI

開發能力 · SDK / AAR

端側能力，交給應用。
硬件細節，留給平台。

業務 App 不需要直接管理模型文件、NPU 主頻或底層驅動。整合 FIH SDK / AAR 後，應用以統一能力接口提交文字或語音請求，由 FIH AI Services 承接模型載入、服務生命週期與推理路由，再經端側運行時調用 MAG1 的本地算力。

01BUSINESS APP→ 02FIH SDK / AAR→ 03FIH AI SERVICES→ 04UNIAI / NN HAL→ 05CPU · GPU · NPU
LOCAL MODELLlmService

管理本地 Qwen2.5 1.5B 模型調用；目前能力口徑聚焦端側翻譯，不包裝為獨立 AI 助理。

TRANSLATIONTranslateService

組織翻譯請求、語言輸入與結果返回，銜接本地語言模型及語音鏈路。

SPEECH TO TEXTAsrService

接收音訊並在裝置端完成語音轉文字，為通話翻譯和語音功能提供輸入。

TEXT TO SPEECHTtsService

將文字結果轉為可播放語音，完成端側語音輸出的最後一段路徑。

APP CALL應用調用的是 FIH 提供的軟件能力接口，不直接控制 AX3596。

RUNTIME ROUTING運行時依模型、算子與後端支援狀態，把工作負載分派至 CPU、GPU 或 NPU。

RESULT推理結果經服務層返回業務 App，讓應用專注於產品流程與使用者體驗。

MAGNE.AI 可提供 SDK / AAR 組件，讓業務 App 依整合範圍調用 MAG1 的端側模型能力。這是一項可擴展的平台能力，不代表目前已向所有第三方應用全面開放。

ROADMAP / WEB3 NATIVE COMPUTE

把本地算力，帶進 Web3 App 與 DApp。

MAGNE.AI 正在推進端側 AI 與 Web3 應用的整合，讓經授權的 App / DApp 能依使用情境調用本地翻譯、語音、意圖理解與 Agent 工作流。敏感交易仍須經過使用者確認、裝置身份與 eSE 硬件簽名邊界；AI 負責理解與協助，不繞過授權。
