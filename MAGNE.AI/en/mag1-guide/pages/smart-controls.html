Home screen and everyday use / smart-controls

Smart controls features

Learn shortcuts, gestures, buttons and assisted touch from this device's own menus rather than instructions for another Android phone.

Entry verified · Operation awaiting verification

Baseline: MA1 · Android 15 · MAG1WW53. Captured: 2026-10-14. This page is an editorial draft. Steps have not been tested except where explicitly stated.

Settings → Smart controls

Before you start

  • Read the options actually inventoried on this page first
  • Record the original switch states before testing
  • Do not try unfamiliar combinations during camera, wallet or call tasks

Steps

  1. Open Smart controls and record each option's English name.
  2. Open the target feature and read its illustration or instructions before determining whether it uses a gesture, button combination or on-screen control.
  3. Before enabling it, understand how to trigger and exit it. Test only on an ordinary, non-sensitive screen.
  4. Record whether it requires an active screen, lock screen or a particular app. One tested scenario does not establish all scenarios.
  5. If an unintended feature is triggered, return to disable its switch and recheck.

Expected result and recorded evidence

The main entry has been found. Detailed inventory and subpage captures retain separate verification states.

Cancel, exit and restore

Disable the item enabled for testing and restore its original switch state without resetting the entire system.

Troubleshooting

  • Does not trigger: check its switch, screen state and gesture requirements
  • Accidental activation: disable the individual feature first
  • Example unavailable: record the page and version for a later capture

Limits and versions

Physical button actions require written explanation; a screen recording shows only the resulting screen behavior.
